# 🚗 Electric Vehicle Inventory Analysis | Power BI

## 📊 Project Overview

This project analyzes an Electric Vehicle (EV) inventory dataset containing
294,193 vehicle records.

The objective of this project is to identify trends in EV inventory,
understand manufacturer distribution, and visualize the growth of electric
vehicles across different model years.

## 🔍 Key Insights

- Total EV records analyzed: 294,193
- Tesla has the highest number of vehicles in the dataset.
- Tesla accounts for 120,899 vehicle records.
- EV inventory shows significant growth in recent model years.
- The dashboard compares the top 10 EV manufacturers.
- Model-year trends help identify the growth of EV adoption over time.
